# Linux学习——第一章 基础

## 一、Linux及其基本概念

### （一）基础概念

Linux 本身并不是一个操作系统，而是一个操作系统的**内核**。

现代的 Ubuntu 等操作系统，是 Linux 的**发行版**，它把 Linux 内核、系统工具、软件包管理工具和其他组件组织在一起，提供可以直接使用的系统。

**终端**是允许用户和命令交互的程序或界面。叫做终端模拟器的原因是它实际上用现代计算机的方法模拟了早期计算机的物理“命令终端”。

**Shell**是负责解释并执行命令的程序，不同 Linux 发行版可能具有不同的 Shell。Ubuntu 的 Shell 是 Bash（可以更换成别的）。

我们可以把终端看作一个交互窗口，把 Shell 看作理解我们的输入内容并安排命令执行的程序。

### （二）文件系统

DOS/Windows 操作系统使用磁盘分区方法将一块或多块磁盘划分为多个区域（卷），在不同区域存储不同内容。不同卷具有不同的盘符（如C、D、E），C盘默认存储操作系统，路径以C:\和D:\等方式开始。

Linux 操作系统的文件系统采取完全不同的设计思路。Linux 采取的是**根目录（“/”）**的设计，所有的文件都是从根目录“/”下开始组织的，所有的存储空间都被划定到根目录下的某个目录。如果系统中有多块磁盘、一个磁盘上有多个分区，或者有U盘驱动器、光盘等插入，可以将这些其他存储设备**挂载**到根目录下的任意文件夹中。

Linux 有下面三种常用的目录概念：

- / —— 根目录。
- ~ —— 主目录，即用户文件夹。
- 当前工作目录 —— 当前处在的位置。可以通过输入 pwd 来查看。

注意：Linux 的目录区分大小写，同时相对路径语法类似 HTML（../assets/和./assets）。

### （三）常见目录

- /home  普通用户的个人目录通常位于这里。
- /etc  主要存放系统和服务的配置文件。
- /usr  包含大量系统程序、共享资源和相关文件。
- /var  存放经常变化的数据，例如日志和部分服务数据。
- /tmp  用于存放临时文件。

## 二、Linux 终端初步

### （一）系统基础命令

- whoami  —— 列出当前用户名。
- uname (-a) —— 列出系统标识信息。-a 是全部信息 (-all) 的意思。
- cat /etc/os-release —— 列出当前发行版的信息。

### （二）终端路径管理命令

- pwd —— 查看当前路径。
- mkdir —— 创建文件夹。
- cd —— 进入路径。

注意 Linux 的进入上级路径是 cd ..，cd和..之间有空格。

### （三）终端文件/目录管理命令

#### ls：查看当前目录下的文件。

若输入 ls -l，则会显示文件的详细信息，包括权限信息。

#### touch：新建一个文件。

```
touch note.txt
```

在当前目录下新建了一个名为 note.txt 的文件。

如果touch的文件已经存在，touch通常只会更新其时间戳，而不是直接将其覆盖。

#### cp：复制文件。

cp是copy的简写，但linux中不能直接写copy。

```
cp note.txt note-copy.txt
```

如果目标文件已经存在，cp 通常会用源文件内容覆盖它。因此，cp是有风险的。

#### mv：移动文件。

mv是move的简写，但同样不能直接使用move。语法是：

```
mv 来源目录/来源文件 目标目录/目标文件
```

如果直接写 mv note.txt note2.txt 则可以把note.txt重命名为note2.txt，实现重命名功能。

#### rm/rmdir：删除文件和目录。

rm是remove的简写，可以删除指定的文件。

```
rm notes.txt
```

这样可以删除 note.txt。

如果要删除目录，可以使用 rm 和 rmdir。但是 rmdir 只能删除空目录，若要彻底删除一个有内容的目录，则可使用 rm -r。

rm 有如下参数：

- -r：递归处理目录及其内部内容（删掉整个有内容的目录）。
- -i：删除前逐项询问。
- -f：表示强制处理，通常会抑制一部分确认和报错。比较危险，不要轻易使用。

在 Linux 终端中，命令的开关参数可以重叠（前提是开关只有一个字符），例如 rm -rf 或者 rm -ri。如果开关互斥，后写的生效。

## 三、Linux 终端文件操作

### （一）基础

#### 1、创建一个有内容的文件

```
printf '第一行：Hello Linux\n第二行：学习文件操作\n' > memo.txt
```

这里有三个新知识。

- printf：按照指定格式输出文本。
- \n：表示换行。
- >：将左边命令的输出写入右边指定的文件。

如果目标文件不存在，> 会创建它；如果文件已经存在，> 通常会先清空原有内容，再写入新内容。这一点非常重要。

如果要追加内容，则使用 >> 而不是 >。

#### 2、查看文件内容（cat命令）

```
cat memo.txt
```

有一个可选开关 -n，决定是否显示行号。

### （二）终端文本编辑器

Linux 提供了一系列基于 TUI 的文本编辑器，修改配置文件等文本文件更便捷。这里先学习 Nano。

```
nano memo.txt
```

nano 可以通过各种快捷键执行操作，如Ctrl + O保存，Ctrl + X退出，等等。

### （三）文件详细信息

#### 1、查看文件类型

Linux 不仅仅使用扩展名来判断文件类型，同时还可以使用 file 命令来根据文件的内容特征，尝试判断文件的类型。

此外，ls 命令也可以粗略查看文件类型：

```
asd@asd-VMware-Virtual-Platform:~/linux-practice/class3$ ls -l
-rw-rw-r-- 1 asd asd 29 10月 28 18:28 hello.txt
```

第一个字符有如下含义：

- - —— 普通文件
- d —— 目录
- l —— 软链接

#### 2、查看文件信息

如果想深入查看一个文件的详细信息，可以使用 stat 命令。

```
asd@asd-VMware-Virtual-Platform:~/linux-practice/class3$ stat hello.txt

访问时间：2026-10-28 18:28:08.492593826 +0800
```

stat 指令可以看见文件的访问时间等元数据。
