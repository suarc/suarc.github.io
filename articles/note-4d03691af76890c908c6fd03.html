一、文档流（normal-flow）

文档流是HTML排列元素的基本方式。HTML/CSS 基本上是按 HTML 顺序自上而下排列元素的，但它同时还将元素分为 块级元素、行内元素、行内块级元素 三类，不同元素有不同排列规则：

1、块级元素（block类）

独占一行，宽度auto（一般为100%），宽、高可以手动设置。

<div> <p> <h1> <ul>

2、行内元素（inline类）

多个邻近元素共享一行（从左到右排列，排满换行），宽高自动确定，不能设置。

<span> <a> <strong>

行内元素只能设定左右margin，无法设置上下margin。

3、行内块级元素（inline-block类）

相当于行内元素，但可以设置宽高。（可用vertical-align实现行内的垂直居中）

<img> <input> <button>

二、显示方式（display）

显示方式规定了HTML元素如何显示，它可以规定：

  • 元素自己如何参加文档流（使元素成为块级、行内、行内块级元素）。

  • 元素内的子元素如何排列（flex、grid）。

注意：display属性是不继承的。

1、普通显示方式

display: none;

最简单的显示方式。这意味着元素不会被渲染，也不占据任何位置，使元素在视觉上不存在。

display: block;                         //成为块级元素
display: inline;                        //成为行内元素
display: inline-block;                  //成为行内块级元素

使元素按块级、行内、行内块级元素显示。

2、Flex/Grid显示方式

display: flex / inline-flex;
display: grid / inline-grid;

这些属性会使元素成为 flex/grid 容器，使直接子元素被块化为块级元素，并且按 flex/grid 方式排列。

若没有 inline- 前缀，则容器本身会成为块级元素；否则容器会成为行内块级元素。

3、元素块化

一些情况下，浏览器会忽略CSS声明，强制将某些元素计算为块级元素，这种情况被称为块化。

块化的常见原因是：

  • 元素作为 flex/grid 容器的直接子元素

  • 元素脱离了文档流（position:fixed / absolute）

这两种情况下，“行内”的概念不存在，元素必须是块级元素。

三、位置（position）

位置属性规定了HTML元素的位置。HTML文档流自上而下排列元素，但position参数可以使元素脱离文档流，按其他方式定位。

（一）对文档流的理解

文档流是HTML文档排列的基础方式，HTML根据一定的规则，自上而下为每一个元素分配位置。这种情况下，元素的位置是依托文档流定位的，例如：

<div>A</div>
<div>B</div>
<div>C</div>

B始终具有一个相对位置：它处在A的下面、C的上面。A、C中有一个固定的位置是留给B的，A、B、C三个元素靠在一起，不管页面如何滚动，都是这样。这就是“参加文档流”。

如果B脱离了文档流，就说明B不再参与HTML文档流的排队，不再在文档流中分到相对位置，而采用其他的定位规则。这样，A、C就直接连在一起了。而B此时可以采取其他定位规则，例如隐藏起来，或始终浮动在A、C的上方、保持在视口顶部/中心而不受页面滚动的影响，等等。

（二）position的参数

1、参加文档流

position: static;            //默认值
position: relative;

position 的默认值是 static，即正常参加文档流，元素的位置由文档流决定，top/left/z-index 等属性无效。

relative 虽然参加文档流，但它允许参照 自己在文档流中的原先位置 改变位置（只是视觉上的偏移，文档流中的实际位置不变）。

除此之外，relative 还经常用于给 absolute 提供定位参照物。

2、脱离文档流

position: absolute;
position: fixed;

这两者都脱离文档流，但决定元素位置的参照物不同。

  • absolute 参照 最近的position不等于static的上层元素 改变位置（如果没有，则相对初始包含块）。如果不设置 top/left 等属性，则元素会停在它原本在文档流中应当出现的位置。

  • fixed 参照 视口（浏览器展示页面的区域）决定位置，页面滚动时位置不变。

3、特殊的参加文档流——sticky

position: sticky;

sticky 参加文档流，但它的位置和滚动有关。

sticky 需要事先设置一个阈值（top/bottom等），元素位置未达到阈值（或者没有阈值）时正常参加文档流、相当于 relative，达到阈值时就被约束在阈值的位置（但它原来在文档流中占有的空间仍会保留）。sticky 的定位参照物是 最近的上层可滚动容器（overflow:auto / scroll / hidden）。

如果sticky的父元素发生了滚动，当sticky碰到其父元素的底部以后，父元素的底部会把sticky托走，sticky元素不再被约束在原有位置。

注意：overflow:hidden只是没滚动条，用户无法滚动（但JS可滚动），也属于可滚容器。如果sticky定位的可滚动容器是overflow: hidden，对用户来说sticky会失效。
