一、进程管理 （一）查看进程 —— ps （二）实时查看进程 —— top （三）结束进程 —— kill 二、前台进程和后台进程

进程（Process）是程序（Program）的一次运行实例。一个程序可以创建多个进程（实例）同时运行，父进程可以创建子进程为自己服务。

为了便于分辨和管理进程，Linux 的进程具有PID（Process ID）；进程的父进程的ID则是PPID（Parent PID）。

一、进程管理

（一）查看进程 —— ps

ps 命令可以列出当前系统中的进程。直接使用 ps 只会给出部分进程（与当前 Shell 和当前用户有关的），要获得更完整的进程列表，需要使用开关 -ef。

ps
示例结果：
    PID TTY          TIME CMD
   4641 pts/0    00:00:00 bash
   5646 pts/0    00:00:00 ps
ps -ef
示例结果：
UID          PID    PPID  C STIME TTY          TIME CMD
root           2       0  0 18:28 ?        00:00:00 [kthreadd]
root           3       2  0 18:28 ?        00:00:00 [pool_workqueue_release]

开关 -ef 是 -e（显示所有进程）、-f（显示所有信息）的合并。

几个字段的意义是：

  • UID —— 运行该进程的用户（注意：UID 实际上是数字，ps 中自动转化为用户名了）。

  • PID —— 当前进程的 ID。

  • PPID —— 父进程的 ID。

  • TTY —— 关联的终端；? 通常表示没有关联控制终端。

  • CMD —— 启动进程时所对应的命令。

  • C —— CPU 使用率（进程整个生命周期的CPU使用率的平均值）。

例如：

ps -f
UID          PID    PPID  C STIME TTY          TIME CMD
asd         6402    4641 99 18:48 pts/0    00:00:00 ps -f

意味着用户 asd 在终端 pts/0 中输入了 ps -f 命令，从而于 18:48 通过 PID 为 4641 的程序启动了 PID 为 6402 的 一个 ps 进程。

如果想要看指定用户的进程，可以使用 -u 开关：

ps -u "$USER"    # 当前登录用户
ps -u asd        # 指定用户的 UID 或用户名

如果要看指定进程的详细信息，可以使用开关 -p（pid）和 -o（output），后者可以决定要看什么信息。例如：

ps -p 10888 -o pid,ppid,stat,cmd
    PID    PPID STAT CMD
  10888   10246 S    sleep 60

上面的命令是查看 PID 为 10888 的进程的 PID、PPID、STAT（state，状态）、CMD信息。

（二）实时查看进程 —— top

ps 查看的是输入命令时的瞬时进程状态。如果想持续跟踪进程和资源的使用情况，可以使用 top 命令。

top - 19:05:20 up 36 min,  1 user,  load average: 0.00, 0.01, 0.00
任务: 343 total ······

 进程号 USER      PR   NI    虚拟    驻留   共享    %CPU  %MEM     时间+ COMMAND
   3609 asd       20   0 4590436 301912 141956 S   4.0   7.6   0:14.71 gnome-s+
······

top 命令会接管 Shell，显示出一个全屏的进程查看界面，其中数据默认 3s 刷新一次。要回到 Shell 时，可按 q 键退出。

与 ps 不同，top 命令可以查看整机的内存、CPU利用率等信息，并且可以动态刷新。CPU利用率等数据是上次刷新~本次刷新之间数据的平均值。

（三）结束进程 —— kill

若要关闭一个进程，可以使用 kill PID 的方法。例如：

kill 10888

注意：kill 本身并不强制关闭程序，而是给程序发送正常的关闭信号，程序可以妥善处理完资源占用后再关闭。

二、前台进程和后台进程

前台进程：直接在 Shell 中运行的进程，会将整个 Shell 窗口占用，此时不能执行其他操作。例如，下面是一个前台进程：

sleep 10

这个命令会使 Shell 停顿 10 秒，Shell 会等待这个命令（创建的进程）执行结束。

如果不想让进程占用 Shell，可以在命令后加上“&”，Shell 将会尝试将其作为后台进程启动。后台进程不会占用 Shell，在此期间可以执行其他操作。例如：

sleep 10 &
[1] 9816

这里的 [1] 9816 就是后台进程的信息。前面的数字是作业编号（Shell 自己管理自己的后台进程用的），而后面的数字则是进程的PID。

要查看当前 Shell 的作业，可以使用 jobs 命令。如果需要查看 PID，可以使用 -l 开关。

sleep 10 &
[1] 10252
jobs
[1]+  运行中               sleep 10 &
jobs -l
[1]+ 10252 运行中               sleep 10 &

要关闭一个 Shell 的后台进程，可以在该 Shell 中使用 kill %作业编号 命令。例如：

kill %1

Shell 开启的前台和后台进程都与 Shell 有关，一旦 Shell 窗口被关闭，进程一般就会终止。如果想使进程不受 Shell 关闭的影响，需要守护进程。守护进程的TTY显示为"?"。
