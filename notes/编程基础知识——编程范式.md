# 编程基础知识——编程范式

什么是编程范式？编程范式是编程时采取的基本思想，它描述了我们如何通过组织程序来解决问题。

## 一、常见的编程范式

### （一）面向过程（Procedural Programming）

把问题拆解为一系列步骤（即**过程**），通过函数组织操作。

面向过程编程关注的是如何一步步完成任务。例如，要计算学生平均成绩，C 语言可采取如下过程：定义学生的数据结构 => 编写计算平均成绩的函数 => 在主程序中调用函数 => 得到结果。

```
#include <stdio.h>

typedef struct {
    char name[20];
    int math;
    int english;
} Student;

double getAverage(Student student) {
    return (student.math + student.english) / 2.0;
}

int main() {
    Student student = {"Alice", 90, 80};
    double average = getAverage(student);
    printf("%f", average);
    return 0;
}
```

### （二）面向对象（Object-Oriented Programming）

把程序中的事物抽象为对象，将数据和相关行为组织在一起，而不是分开放置。

```
const student = {
    name: "Alice",
    math: 90,
    english: 80,
    getAverage: function() {
        return (this.math + this.english) / 2;
    }
};
console.log(student.getAverage());
```

面向对象是 JavaScript 的重要特点。上面的例子中，学生的数据和计算学生平均成绩的方法都存放在 student 对象中。

### （三）函数式编程（Functional Programming）

将计算看作函数之间的组合，尽可能减少副作用，强调数据转换和函数的可组合性。例如：

```
const numbers = [1, 2, 3, 4, 5];
const result = numbers
    .filter(n => n % 2 === 0)
    .map(n => n * 2);
console.log(result); // [4, 8]
```

这里没有显式地编写循环来逐个处理元素，而是将数据依次交给不同的函数进行转换。

函数式编程还有一些重要思想：

- 纯函数：相同输入总是产生相同输出，不产生外部副作用。
- 不可变性：尽量不直接修改已有数据。
- 高阶函数：接收函数作为参数，或者返回函数。
- 函数组合：**将多个小函数组合起来完成复杂任务**。

JS 中的 map、filter、回调函数等，正是接触函数式编程的重要入口。

### （四）声明式编程（Declarative Programming）

核心思想：描述想要什么结果，而不是详细描述如何一步步得到结果。

例如，比较两种写法：

#### 命令式：告诉计算机具体怎么做

```
const numbers = [1, 2, 3, 4, 5];
const result = [];
for (const n of numbers) {
    if (n % 2 === 0) {
        result.push(n);
    }
}
```

#### 声明式：描述想要什么

```
const numbers = [1, 2, 3, 4, 5];
const result = numbers.filter(n => n % 2 === 0);
```

第一种写法强调执行步骤，第二种写法强调结果要求。

这里顺便引出一个相关概念：

- 命令式编程（Imperative Programming）：告诉计算机怎么做。
- 声明式编程（Declarative Programming）：告诉计算机要什么。

注意，命令式和声明式与面向过程、面向对象并不是完全平行、互斥的分类。它们描述程序的角度有所不同。

### （五）逻辑编程（Logic Programming）

核心思想：通过描述事实和规则，让计算机根据逻辑关系推导结果。

例如，假设有以下事实：

```
parent(alice, bob).
parent(bob, charlie).
```

以及规则：

```
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
```

它表达的是：如果 X 是 Y 的父母，并且 Y 是 Z 的父母，那么 X 就是 Z 的祖父母。

我们可以向系统提出问题：

```
grandparent(alice, charlie)?
```

系统根据事实和规则进行推导。

这类编程范式常见于 Prolog 等语言，在人工智能、知识表示、规则推理等领域有应用。

## 二、不同范式之间的关系

编程范式只是编程的基本思想、设计哲学，不同编程语言的特色编程范式不同（例如C语言主要是面向过程的），但它们并不是互相排斥的。例如，JavaScript 可以同时采用：

- 面向过程：使用函数和流程组织程序。
- 面向对象：使用对象、原型和类组织程序。
- 函数式：使用纯函数、map、filter 等进行数据转换。
- 声明式：使用更高层次的表达方式描述目标。

编程范式可以从不同角度理解：

- 程序组织方式：面向过程、面向对象、函数式、逻辑编程。
- 表达程序的方式：命令式、声明式。

而且，不同的编程范式只是帮助理解的分类视角，不是严格的学术分类树，不同范式之间可能重叠、组合。

编程范式不是编程语言的等级，也不存在一种范式在所有场景下都最好。例如，简单的数据处理可能适合函数式写法；复杂业务系统可能适合面向对象的组织方式；底层系统程序可能大量采用面向过程的方式。真正重要的是：理解不同范式的思想，知道它们各自擅长解决什么问题，**在适当的时候采用适当的范式**，而不是刻意让所有程序都采用同一种范式。
